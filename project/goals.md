# Vision

`reachy-mini-app` is the nolte portfolio's home for application-level Reachy Mini
behaviours. Built on the Pollen Robotics / Hugging Face `reachy_mini` SDK, it
packages robot behaviours (for example dance-to-music) that run on the Reachy
Mini and distributes them as a Hugging Face app. It is deliberately a playground
project and stays experimental while behaviours mature.

## Outcomes

- **O-1** — Reachy Mini owners run packaged robot behaviours (for example
  dance-to-music) on their own device. _(audience: Reachy Mini owner / maker)_
- **O-2** — the maintainer packages behaviours on the `reachy_mini` SDK and
  distributes them as a Hugging Face app. _(audience: Maintainer (`nolte`))_
